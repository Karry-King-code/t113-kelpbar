## 这版镜像的改动

**改的是 SDK 源文件，不是板上临时文件** —— 所以烧录后自带全部配置：

**改动文件**：
```
~/T113-Tina5.0-V1.2/openwrt/target/t113/t113-evb1_auto_nand/base-files/etc/rc.local
（330 字节 → 1618 字节）
```

**改动内容**：
1. 音频子系统就绪等待（避免时序竞态）
2. `HPOUT Switch` = on
3. `HPOUT Gain` = 7（0dB，出厂是 3）
4. `DACL/R Volume` = 200（出厂 160）
5. **喇叭功放使能** `PA_SHDN`（PB2 / gpio-34）**拉低 = 工作** ← 本关关键（高电平=关断）
6. 显示彩条（考核④的配置也保留下来的）

## ★ 为什么改 SDK 源文件很重要

之前的做法是在**板子上**改 `/etc/rc.local`。问题：

```
板子的 /etc/rc.local  → 实际存在 /overlay/upper/etc/rc.local（可写层）
重烧固件 → overlay 被清空 → 配置全丢！
```

改 SDK 源文件后，配置**编进 rootfs**，**每次烧录都自带**。
