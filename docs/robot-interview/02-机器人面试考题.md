# 机器人方向面试考题（二）· 先做题

> **用法**：学完《01-知识讲解》后，先自己作答（口头或写下来），再翻《03-答案》对照。★ 数量 = 面试出现频率（★☆☆ 少见，★★★ 高频）。
> **A 组是你的主场**（项目题）——机器人面试 70% 时间聊项目，这组必须张口就来。

---

## A 组 · 项目实战题（基于你的 T113 项目，8 题）

1. ★★★ 介绍一下你做过的嵌入式 Linux 项目。（开场必问，30 秒版和 2 分钟版都要备）
2. ★★★ 你们的板子和官方评估板有什么区别？你做了哪些"移植"？举个例子说明移植的本质。
3. ★★★ Linux 系统的启动流程是怎样的？你在项目里哪个环节碰到过启动流程的问题？
4. ★★☆ 你说调试串口的移植要改三个地方，为什么是三个？各管哪个阶段？
5. ★★★ 设备树是什么？为什么需要它？举一个你实际修改设备树的例子。
6. ★★☆ 你是怎么排查"内核启动卡死"这类问题的？（考察调试方法论）
7. ★★☆ 你怎么验证一个外设"真的在正常工作"而不是"命令没报错"？（举录音或显示的例子）
8. ★★★ 项目里你遇到的最难的问题是什么？怎么解决的？（备一个有定量分析的故事）

## B 组 · Linux 系统基础（15 题）

17. ★★☆ 进程间通信（IPC）有哪些方式？各自适合什么场景？
18. ★★★ 共享内存是最快的 IPC，为什么还要配信号量一起用？
